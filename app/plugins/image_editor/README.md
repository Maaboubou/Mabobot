# 生图

发送「生图 海边日落」即可开始。可以在引用回复的正文里使用同样的指令。引用一张照片时，这张照片会用作整项任务的参考图。无法读取时，插件会请你重新引用图片。

在插件默认设置或聊天的插件设置中，可以修改触发词、每批张数（默认 1）、最多尝试批次（默认 3，含首批）及同批请求发起间隔（默认 10 秒）。每次单图请求的处理时限默认 300 秒。

插件按间隔发起一批独立的单图请求，并等本批请求结束。一批成功生成至少 1 张就发回该批的全部成功图片。3 张起通过微信合并展示，1 或 2 张直接发送。整批 0 张时开始下一批；所有批次均为 0 张时，插件会回复实际尝试批次。生成后微信发送失败时，保留图片供重发。

跟随默认、Codex 内置和 API 模式沿用原插件的图片生成设置。内置模式使用全局默认的官方 ChatGPT Codex Profile。API 模式使用配置中的渠道，并沿用原有渠道回退规则。本插件请求静态 PNG，以便交付为微信照片。图片保存在插件的 generated 目录，并登记到当前聊天的图片资产索引。

插件 ID 为 `image_editor`，现有权限、聊天配置及生图渠道绑定继续使用。
