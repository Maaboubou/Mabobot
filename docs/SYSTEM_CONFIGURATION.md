# 系统设置与配置归属

系统页只管理跨能力共享、且确实由当前运行架构读取的本机设置。数据库中出现一个键，不代表它应该自动成为普通表单字段；键必须声明归属、配置来源、生效方式和是否需要重启。

## 唯一编辑入口

| 配置 | 唯一入口 | 保存位置 | 生效方式 |
|---|---|---|---|
| 模型、供应商、API 地址、模型密钥、LLM 代理 | 模型与调用 → 模型连接 | 模型 JSON + 本机凭据数据库 | 新调用读取；连接可单独测试 |
| 微信机器人身份 | AI 助手 → 聊天配置；系统页仅保留全局备用名 | 聊天记录 + 本机数据库 | 自动识别优先；全局备用名建议重启后使用 |
| 飞书、GitHub、Codex 代理保护 | 系统 → 外部服务 | 本机数据库 | 按服务读取方式生效 |
| 邮箱提醒 | 系统 → 通知提醒；启动器 → 设置 → 邮箱提醒（共用表单） | 本机数据库 | 保存后立即生效；支持测试邮件 |
| 数据库地址、Web 端口 | `.env` 或启动命令 | 进程环境 | 必须重启 |
| 插件业务参数 | 自动化与能力配置 | 插件配置 | 按插件声明生效 |
| 群聊触发、角色、档案查阅 | 聊天配置 | 本机数据库 | 当前聊天生效 |

模型连接的“本机共享凭据”采用 `env::NAME` 引用格式。Web 界面可直接保存 `NAME` 的真实值，但 API 永远只返回“已配置/未配置”和来源，不返回密钥。这样 `data/llm_models.json` 可以作为分享配置，而真实值留在被忽略的本机数据库或 `.env`。

## 引用视频语音识别

AI 助手处理引用视频时，将四张等间隔抽帧与同一视频的本地语音转写一起提交给模型。语音识别复用摘要插件 `summary_plus` 的 SenseVoice 模型与单任务执行槽，无需另行安装模型，也不要求触发一次链接摘要。

配置沿用摘要插件的 `local_asr_enabled`、`local_asr_max_duration_minutes`、`local_asr_timeout_seconds` 和三个 `local_asr_*_path` 资源路径。关闭 ASR、超过时长上限、无可识别语音或识别失败时，助手继续使用四张抽帧。临时音频在处理后清理，原视频保留。

本地 ASR 模型、运行程序或 VAD 缺失时跳过语音识别并记录警告。引用视频流程只查找本机已有的 FFmpeg/FFprobe（摘要插件配置、环境变量、项目工具目录、static_ffmpeg 缓存和系统 PATH），不在消息处理中自动下载。工具缺失或抽帧失败时，记录警告并降级为文字回复；模型会被告知未取得视频内容，不借用历史图片猜测。技术故障不直接发送到微信，问题确实需要视频内容时可简短请用户描述。

提交给模型的转写最多 20000 字，超过时明确标注截断；提示会说明转写未经核实、可能严重误识别，仅作辅助参考，需结合画面和可核实信息判断，不能当作可靠字幕或直接听到的音频。

## 微信备用名称

群聊中的有效机器人名称按以下顺序确定：

1. 自动读取微信群详情里的“我在本群的昵称”；
2. 该聊天手动填写的备用名称；
3. 系统页的“全局备用 @ 名称”。

因此，全局字段不是微信账号展示名，也不是通常需要日常维护的值。项目能成功自动获取群昵称时，它不会覆盖自动结果。填写或修改它会改变自动识别尚未成功时的 `@名称` 匹配，还会影响少数历史消息和日志中的机器人/用户归类。部分插件在初始化时缓存该值，所以界面标记为“需重启”。

## 启动环境与扩展键

Web 端口、数据库连接等值在应用读取当前数据库之前就已经确定，不能通过修改数据库里的同名行来切换。系统页只展示当前来源和状态，不提供无效输入框。

“高级设置”用于脚本和插件声明的扩展键，以及应用内部状态。只有对应文档明确要求时才应修改；核心功能需要在系统设置字段注册表或插件配置规范中声明归属。

## 邮箱提醒

Web 入口为 `/system/notifications`，启动器的设置页提供相同表单，Web 服务未启动时也可配置和测试。支持 QQ、163、126、Gmail 预设和自定义 SMTP（SSL/TLS 或 STARTTLS），填写授权码，收件邮箱留空默认发给自己。保存后再点击“发送测试邮件”；测试仅发送固定测试文字，不包含业务内容。

新安装默认关闭。已有 `QQEMAIL_ADDR`、`QQEMAIL_CODE` 配置继续兼容：首次保存到新表单时保留旧授权码，随后以新配置为准；显式关闭或清除授权码后不会重新启用环境变量中的旧值。授权码留空代表保留，清除需勾选专用选项并关闭提醒。

邮件由本机直接通过用户指定的邮箱服务商发送。凭据保存在本机数据库，API 不返回明文；最近 20 条发送记录只保存事件类型、时间和结果，不保存正文、收件地址或二维码。含数据库的备份仍包含邮箱配置和凭据，应按现有备份规则保管。

微信掉线及扫码、恢复在线、B 站 Cookie 失效和开机自动登录失败使用统一配置；个人使用的 `Ping_notify.py` 保持原有环境变量方式。未开启的提醒直接跳过；发送连接设置 15 秒超时，同一事件失败后 5 分钟内不重复尝试，后续是否再次提醒由业务事件决定。测试按钮的成功表示 SMTP 接收了邮件，并不保证最终投递到收件箱。

### Gmail

Gmail 预设使用 `smtp.gmail.com:465` 和 SSL/TLS。先开启 Google 两步验证，再在 [Google 应用专用密码](https://myaccount.google.com/apppasswords) 创建用于 Mabobot 的密码；复制时包含的分组空格会自动去除。不要输入 Google 账号登录密码。部分组织账号、安全密钥专用的两步验证配置或高级保护账号可能没有应用专用密码入口，参见 [Google 官方说明](https://support.google.com/accounts/answer/185833?hl=zh-Hans)。

当前版本使用 SMTP，尚未接入 Google OAuth。官方 Gmail API 支持仅申请 `gmail.send` 发信权限，后续可提供浏览器授权并将令牌保存在本机；面向公众发布需配置 OAuth 客户端并按 Google 要求完成相应验证，参见 [Gmail API 权限说明](https://developers.google.com/workspace/gmail/api/auth/scopes)。
