# Mabobot v3.8.0：调用记录对齐列表与内置图片检索

## 调用记录与性能

- 调用记录改为按日期分组的对齐列表，固定显示模型、聊天、输入 / 输出、缓存命中率、总耗时、首字与生成速度。
- 点击记录展开 Token 用量、响应性能、请求、思维和响应；请求正文与附件按需加载，保留原有附件查看和下载。
- 手机端按容器宽度重排；兼容明暗主题与键盘操作，长聊天名称完整换行。
- 增加流式生成计时和用量记录；估算速度标注 `≈`，缺少数据时显示 `—`，并在详情解释原因。多次模型请求不显示不完整的平均速度。

## 内置图片与引用视频检索

- App Server 增加 `wx_lens.search` 与 `wx_lens.read`，按需使用当前轮图片或引用视频帧检索来源。
- 在“角色管理 → 系统规则 → 图片与视频检索”管理规则、超时、并发、缓存及环境状态。
- 检索继承聊天在线研究和工作区权限，提供请求绑定、任务取消、进度、缓存和错误状态。
- 图片检索会上传本轮选定图片至 Google；保留明确的禁用入口与错误说明。部署与配置见 [图片检索说明](https://github.com/Maaboubou/Mabobot/blob/v3.8.0/docs/google_lens.md)。

## 聊天记录与稳定性

- 增加每聊天记录开关，与聊天记录插件授权保持一致；完善附件本地路径补充及关键词检索。
- 修复 Windows 下生成 WSL 附件路径的分隔符；改善引用视频回退、历史时间识别和长消息尾部跟随。
- 改善 Codex 权限待检测状态、模型搜索能力元数据处理，以及游戏发售月报的模型路由与运行流程。

## 升级说明

1. 更新源码后，在宿主虚拟环境执行 `python -m pip install -r requirements.txt`。内置 Lens 使用固定版本的 Patchright，并需要本机 Chrome、Edge 或 Chromium；运行时不会自动下载浏览器。
2. 完整重启启动器、Bot 与 Web 服务，然后刷新控制台。
3. 保留 `.env`、`data/` 和现有浏览器 Profile；检查聊天记录开关及图片检索配置。

备份格式与插件 Runtime API 继续使用 v2。本次提供 GitHub 自动生成的源码归档，不含本机配置、运行数据或私有插件。
