# Mabobot v3.9.0：共享任务进度与交付去重

## 插件与助手协作

- 插件与助手共享按聊天隔离的任务进度，助手可以查询现有任务和真实交付状态。
- 插件通过能力声明识别相同资源与参数的并发工作，复用进行中的任务或有效期内的结果。
- 关闭助手不会停止独立运行的插件任务；旧插件的托管任务也可登记进度。

## 文件与消息交付

- 分别记录执行完成和发送确认，避免把任务完成误报为文件已送达。
- 同一任务按交付意图与文件内容识别重复发送；未确认的发送保留待核对状态。
- 用户明确要求重发时，复用当前聊天留存的文件并重新审核，无需再次生成或下载。
- 下载工具要求保留原始分享链接，便于与摘要插件共享媒体下载进度。
- 延续媒体登录状态检查与小红书视频时长限制修复。

## 升级说明

1. 更新源码与依赖后，完整重启启动器、Bot 和 Web 服务。
2. 保留现有配置及运行数据。首次使用会创建 `data/shared_work.sqlite3`，文件快照保存在相邻的 `shared_work_files` 目录。
3. 已结束且没有未确认交付的文件快照保留 7 天；任务与交付记录继续保留。

备份格式与插件 Runtime API 保持 v2。公开发行仅提供 GitHub 自动源码归档。

公开库每次发布后仅保留最新一个已发布 Release（含预发布），草稿保留；清理旧 Release 会删除其附件，历史 Git 标签、提交和仓库内版本公告保留。
