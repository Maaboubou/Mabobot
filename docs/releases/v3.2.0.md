# Mabobot v3.2.0：原始聊天档案、持久线程与模型用量

本版用可查询的原始聊天档案替代旧生成式记忆系统。每个聊天复用独立 Codex 线程，按需查找历史，减少重复上下文与后台模型维护；同时完善用量计价、媒体下载和 Web 稳定性。

## 2026-09-08 修订：微信发送者识别

- 移除发送者、方向及来源的跨消息缓存，避免微信复用控件时将同内容表情归到旧发送者。
- 按 wxautox4 实测顺序执行头像右键、中键和焦点读取；保留目标窗口校验、三轮重试上限及消息去重、历史恢复机制。
- 补充头像识别日志，记录发送者及控件标识，便于定位后续异常。
- 清理不再使用的 Alembic 依赖，公开版同时移除不再使用的 curl-cffi；NumPy 归入媒体依赖分组。

此修订直接更新 v3.2.0 的源码归档。此前已下载 v3.2.0 的用户需重新获取代码并重启微信 Bot。

## 聊天档案与成员

- 升级现有聊天记录插件，先保存原始消息，再执行回复。归档、索引及成员目录维护无需后台模型提炼。
- Codex 可搜索原话、展开前后文、按日期查询，也可取得当前聊天的完整本地 SQLite 工作副本进行统计与总结。
- 新增聊天档案页面：按需分页加载、原文展开、覆盖查询、导出、固定导航和成员别名维护。
- 成员只需要当前昵称与别名，支持手动修改、删除和按拼音排序；Codex 查阅中可维护明确的新别名，并在确认改名后合并成员。
- 移除旧事件记忆、人物画像、阶段摘要、向量引擎及对应页面、路由和依赖。

## Codex 上下文

- 首轮提供最多最近 50 条聊天资料；后续按归档游标追加新增或修订内容，保留同一聊天的线程。
- 上下文窗口设置对官方登录与 API Key Profile 均实际生效，主动压缩阈值为配置窗口的 90%。
- 聊天链路取消旧的 22 万 Token／两次压缩换线程限制。原生压缩不重置轮数，当前线程与累计轮数分开统计。
- 角色或运行配置变化、长时间空闲及线程异常仍可重建；工具权限继续按聊天隔离。
- 运行中心用服务端最新请求用量显示上下文，避免把累计调用输入当成窗口占用。缓存仍占上下文，命中与速度收益因任务而异。

## 用量与稳定性

- 新增请求级用量账本，支持按调用类型、聊天、时间范围下钻，分别记录普通输入、缓存读写、输出、推理与失败尝试的已知用量。
- 区分供应商上报、价格快照、自定义计价及未知费用；Codex 显示标准 API 等值估算，不代表 ChatGPT 订阅实际扣款。
- 修复浏览器工具 WebSocket 路由中的同步关闭卡顿，健康详情移出主事件循环，降低 Web 整体无响应风险。
- Weekly 使用默认 Codex Profile 的实际模型，移除单独模型名覆盖。
- 抖音下载支持 iesdouyin 分享链接与浏览器 Cookie；复用时长检查取得的完整元数据，减少重复详情解析。

## 本次同时发布的功能

- 引用视频结合四张抽帧和本地 SenseVoice 转写；依赖缺失时降级，不在消息处理中自动下载模型。
- 统一邮箱提醒配置，Web 与启动器共用配置和测试入口。
- 新增游戏发售日历插件，通过统一推送权限管理月度发布。
- Codex 辅助模型使用独立单次文本任务；微信成功发送的文件自动进入引用索引。

## 升级说明

升级前备份运行数据。旧记忆页面及 API 已移除；旧原文和已维护别名可通过迁移工具保留，生成摘要不能还原为原始聊天。确认迁移结果后再清理旧数据库与向量缓存，不要仅按连接名称删除其他插件仍使用的模型。

新用量账本不导入旧汇总。旧线程首次回复时切换到增量上下文策略；原生压缩后的大小由服务端决定，90% 仅为触发阈值。

安装或更新后运行 `START.bat`。详见 [聊天档案与升级说明](../CHAT_ARCHIVE_OPERATIONS.md)、[模型用量](../LLM_USAGE.md) 和 [模型配置](../MODEL_CONFIGURATION.md)。
