# Mabobot v3.9.1：共享任务上下文与图片识别修复

- 共享任务状态放在真实用户消息之前，避免遮挡当前图片、视频帧与用户问题。
- 统一识别真实用户消息，图片检索与请求分析跳过框架附加状态。
- 仅自动附带与当前消息或原始资源链接关联的任务；进度追问通过任务工具查询。
- 默认隐藏聊天记录插件的内部工作，优先展示运行中与发送待核对的任务。
- 增加任务时间与明确的交付状态，区分无需交付、状态未知、待交付、发送待核对及发送成功。

更新后重启后端服务以加载修复；保留现有配置与运行数据。备份格式与插件 Runtime API 保持 v2。
