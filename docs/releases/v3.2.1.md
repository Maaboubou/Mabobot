# Mabobot v3.2.1

本次维护版本重点改善微信启动监听速度、托盘恢复和启动器关闭体验，并修复近期日志中发现的权限查询与链接卡片读取问题。

## 启动监听更快

- 优化监听窗口查找与创建。微信主窗口就绪后立即恢复已启用的监听，与 Web 和插件初始化并行执行。
- 启动期间收到的消息会等待 Web 健康检查通过后再转发，减少服务尚未就绪时的转发失败。
- 修复所有微信窗口关闭到托盘后，重新唤起主窗口却迟迟不开始添加监听的问题。

## 关闭启动器时可选择退出

- 首次关闭时可选择“最小化到系统托盘”或“停止服务并退出”。
- 勾选“记住我的选择，不再询问”后，后续关闭按保存的方式执行；也可选择每次询问。
- 可在“设置 → 窗口行为”中随时修改。完全退出会停止微信 Bot 和 Web 服务。

## 稳定性修复

- 摘要权限查询只读取授权所需字段，避免旧模块字段迁移影响查询；无权限或查询失败时拒绝处理。
- 微信浏览器菜单控件因刷新失效时，在原有超时范围内重新查找，改善链接卡片 URL 读取稳定性。
- 模型调用失败日志记录错误类型和状态码，方便排查供应商额度、网络和服务异常。

## 更新说明

更新源码后重新启动启动器，使关闭方式设置和后端改动全部生效。已有监听开关和其他启动器偏好会保留。

本次沿用源码发行方式，可使用下方 GitHub 自动提供的源码归档；依赖安装与启动方式见[本版本 README](https://github.com/Maaboubou/Mabobot/blob/v3.2.1/README.md)。
