# Mabobot v3.10.1：浏览器标签页自动回收

- 修复共享 Chrome 网页读取持续堆积标签页的问题：本次调用新建的标签页在读取完成、异常、超时或取消后自动关闭。
- 保留调用前已有的标签页、共享浏览器和登录状态，继续支持刷新匹配网址的已有页面。
- 标签页及客户端清理失败时记录警告，便于排查残留。

更新后重启 Mabobot 后端服务使修复生效。此前累积的标签页不会自动批量关闭，可自行清理；本次更新不会清除 Cookie 或浏览器配置。备份格式与插件 Runtime API 保持 v2。

验证覆盖正常读取、重复访问、重定向、超时、异常、取消，以及已有页面和 Cookie 的保留。
