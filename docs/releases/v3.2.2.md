# Mabobot v3.2.2：消息恢复与监听稳定性

本版汇总 v3.2.0 之后的公开更新，重点修复消息恢复中断、历史翻页异常和插件启动并发问题。

## 消息恢复与监听健康

- 消息游标恢复连续失败后进入冷却并定时重试，保留旧基线，避免停止恢复或跳过待交付消息。
- 修复定向滚轮步数、历史页面衔接、动画等待及失效控件矩形处理；恢复向下收集到确认底部，并保留页数和时间限制。
- 监听健康状态区分线程存活与消息交付正常，显示恢复、冷却、轮询错误和停滞状态；恢复交付后清除降级状态。
- 修复插件发现期间查询来源路径可能触发的注册表并发修改错误。

## 助手与网页体验

- 示例角色和判断器可编辑、删除，初始化标记避免重启后恢复已删除项；角色变更及时刷新聊天选项并保留未保存编辑。
- 插件设置支持选择推送接收对象，推送授权与消息处理授权独立；修复设置弹窗异步覆盖及保存状态问题。
- 消息消费遵循各监听器的传播策略，清理弃用的记忆、Detail 和 Hermes 模型路由。
- 生图使用默认官方 Codex Profile，由宿主交付生成图片，修正图片已发送后的超时提示。
- 修复监听窗口缩小后的恢复与多显示器枚举，为浏览器标签添加 Mabobot Logo，并完善 Tailscale 设置提示。

## 升级

- 更新源码后完整重启 Mabobot，使微信 Bot 与 Web 服务加载新代码；刷新网页获取静态资源。
- 保留现有 `.env`、`data/` 和本机配置。本版不变更备份格式或插件运行接口版本。
