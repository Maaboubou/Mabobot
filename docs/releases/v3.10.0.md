# Mabobot v3.10.0：计划任务、条件监控与聊天交互改进

- 新增聊天与 Web 计划任务：一次性、每日／每周多时刻、固定间隔与时段排期，支持起止日期、定时暂停、单次跳过和改期。
- 新增条件监控、事件去重与有限目标进度；无变化时静默，目标完成后自动结束，执行结果与发送状态独立保存。
- 计划任务按聊天授权并校验创建者与角色边界，支持反馈修订、版本恢复、失败处理与未交付结果恢复。
- 群聊回复支持真正的微信多人 @，兼容群昵称与联系人备注差异；无法唯一定位成员时停止发送。
- 改进聊天图片与附件原图读取、消息内容审核和文件交付；普通聊天与计划任务复用共享 Chrome。
- 集中管理模型路由提示词，完善移动端布局；新增 Codex Profile 快速模式开关，修复 CLI 版本检查与用量记录。

- 修复启动器 Codex 环境检测：按实际配置识别 WSL／Windows 运行环境，后台刷新并区分 CLI 缺失与检测失败。

更新后完整重启 Mabobot 并刷新 Web 控制台。计划任务需要应用服务持续运行；管理员需在“计划任务”页面为聊天明确启用权限。任务数据库、任务资源和结果附件应一起备份。保留现有配置与运行数据，备份格式与插件 Runtime API 保持 v2。
