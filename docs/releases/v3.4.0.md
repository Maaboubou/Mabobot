# Mabobot v3.4.0：翻译助手、概览与控制台统一

本版新增公开版翻译助手，支持每个聊天独立设置双语／三语互译；重做概览，集中展示运行状态、活动趋势、模型用量和事件，并统一控制台的明暗主题与移动端交互。

## 翻译助手 2.0.1

- 公开版新增翻译助手插件。通过统一模型配置为 `builtin_translation / translate` 分配模型，在聊天页授权启用。
- 显式选择双语或三语，可调整语言顺序、编辑提示词，并用目标语言原生名称显示译文标签。
- 全局默认与本聊天设置分开，保存后直接生效；只保存改动字段，其余继续跟随默认，可逐字段恢复。
- 语言与提示词可保存为模板、导入、重命名和删除；导入形成独立副本，不影响其他聊天。
- 支持最终提示词预览和试译；试译只显示在网页，不发送微信消息。
- 保留微信表情标记、型号下划线和原文参数；加强结构化输出校验，修复数字与表情识别问题。

## 概览与活动

- 概览集中展示运行状态、今日消息与回复、活跃聊天、费用、调用趋势、Codex 额度、模型用量和事件时间线。
- 增加最近 24 小时活动与七日趋势；聊天日志增量索引减少重复全量扫描。
- 实时状态每五秒刷新，显示最近消息与回复数量、最后消息时间；切换页面或后台时停止轮询，读取失败保留上次数据并标记状态。
- 待处理事项默认折叠，停止复发的历史错误在 24 小时后退出概览队列；完整历史仍可在运行页面查看。
- 活动图支持悬浮、手机点按和键盘读数。修复手机柱子重叠、回复段比例和图表裁切，时间线状态与筛选分行显示。

## 控制台统一

- 收敛字体、圆角、阴影与主题令牌，统一日志表面、表格列宽、时间和数字格式。
- 用量列表支持整行展开，名称列与其他列反馈一致，保留键盘操作。
- 确认框补齐读屏说明、初始取消焦点和关闭后焦点恢复；连续确认按顺序展示。
- 设置定位遵循减少动态效果偏好，修正恢复备份等危险操作的确认样式。

## 升级与使用

1. 升级前备份当前数据，更新源码时保留 `.env`、`data/` 和已有本机配置；通过 `START.bat` 启动并重启 Bot 与 Web 服务，刷新控制台。
2. 翻译助手首次启用前，在模型配置中分配翻译模型，再到聊天页启用插件；聊天独立配置不自动授予插件权限。
3. 若曾自行安装旧版翻译插件，请先备份旧提示词，并在新的全局默认或聊天设置中重新录入。旧 `prompt_translate` 不会在启动时自动转换；标准升级不执行任何本机专用迁移。
4. 新的聊天插件配置与模板表由正常数据库初始化创建；本版保持备份格式与插件 Runtime API v2 不变。
