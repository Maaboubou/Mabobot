# Mabobot v3.11.0：图片生成中心与微信消息恢复

## 图片生成与编辑

- 新增“模型配置 → 图片生成”页面，管理 Images／Responses API 渠道、模型、参数、测试生图及脱敏调用记录。支持引用 API 类型的 Codex Profile 连接信息、模型目录发现和手动模型名。
- 支持全局、聊天及插件分别配置生图模式和渠道顺序。API 渠道耗尽后可使用 Codex 内置生图补齐剩余结果，部分成功的图片会保留；本地参数校验失败不会触发内置回退，取消或交付失败不会重新生图。
- 支持多参考图、蒙版、标注、GIF／SVG 输出与静态帧合成动图，具体格式取决于渠道和模型能力。可由管理员允许聊天请求临时切换本次生图模式，默认关闭。
- 新增持久图片资产与版本索引，记录成品、批次及实际交付状态。支持跨轮继续编辑历史原图或已生成图片、恢复中断结果及直接重发；本地导出重发不调用生图 API。
- 图片编辑和 Weekly 复用图片生成配置；默认图片快照目录纳入生成内容备份及存储统计。
- 公开版 Weekly 按配置显示编辑署名，未配置管理员时不发送管理通知。

## 微信消息与任务交付

- 支持读取微信引用动画表情，按引用身份、资源哈希及缩略图核验原文件。无法确认唯一来源时明确失败；开启附件记录后可在历史工具中复用原始动图。
- 改进监听启动和历史恢复时的消息来源时间隔离，避免借用旧页面时间；未读消息逐页跟随，返回最新消息时验证列表底部稳定。
- 完善任务取消与发送期限校验，已在执行期限内生成的结果可在固定宽限期内完成交付。调用记录区分生成、发送失败、发送被拦截与已发送状态。

## Codex 运行与更新

- Codex 版本检查独立于控制台页面，在北京时间每日 08:00 后台执行；显示最近成功、失败与下次检查时间，并提供全局更新入口。
- 合并并发检查，避免检查与安装更新互相竞争；保留手动检查及更新流程。
- 为已授权的计划任务增加社区新闻检索工具，保留公开证据、来源状态与时间信息；使用前需在对应 Profile 安装所需工具并完成来源配置。

## 升级说明

更新项目依赖后，完整退出并重新启动启动器、Bot 与 Web 服务，再刷新控制台。默认继续使用 Codex 内置生图，新 API 渠道需自行配置并启用；API 测试生图会调用选中的真实渠道。

图片资产默认保存在 `data/image_generation/assets`，使用自定义外部资产目录时需一并备份与迁移。SVG 交付仍需管理员文件许可，升级不会自动扩大现有文件许可清单。微信引用表情能力依赖本机微信环境，请按实际客户端完成验收。

备份格式与插件 Runtime API 保持 v2，无新增主数据库迁移。
