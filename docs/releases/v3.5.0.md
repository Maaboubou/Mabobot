# Mabobot v3.5.0：权限中心、角色管理与聊天配置

本版集中完善 Codex 权限控制、角色与系统规则管理，并让插件配置按聊天独立生效。

## 主要更新

- 新增权限中心：群聊、私聊默认权限及聊天覆盖，统一文件、网络与在线研究边界；支持版本冲突检查、保守迁移和运行时应用状态。
- 角色管理默认展示角色列表，接话判断独立为次级标签；新增系统规则编辑、版本恢复、提示词草稿预览、无发送副作用的试判和真实请求快照。
- 插件统一支持默认配置、聊天独立保存与恢复默认；入站消息、后台任务和定时推送按聊天读取配置，图片识别结果原位补充到聊天记录。
- 新增微信附件内容审核设置，结合配置规则检查下载文件与最终附件；启用时需分配支持图片的审核模型。
- 优化聊天管理布局、角色和模型卡片、聊天档案长消息交互，以及概览趋势、模型用量、额度和活动统计；改善手机与明暗主题体验。
- 修复角色及接话判断保存时的误报版本冲突、全局设置入口无响应，以及上下文遗漏图片识别描述等问题。

## 升级说明

1. 升级前备份数据，保留 `.env`、`data/` 和本机配置；安装更新后的 `requirements.txt` 依赖。
2. 重启 Bot 与 Web 服务并刷新控制台，新表由正常数据库初始化创建。升级后检查权限中心的有效权限与运行状态。
3. 旧角色和判断规则进行保守迁移并保存原记录；在角色管理中检查系统规则和提示词预览。
4. 附件内容审核默认开启；升级前为 `assistant / content_review` 分配支持图片的模型，并检查 `config/wechat_content_policy.json` 中的审核规则。缺少审核模型、审核失败或内容不被允许时，相关附件会被阻止；可在聊天配置中调整审核开关。
5. 聊天插件配置不自动授予插件权限；本版继续使用 GitHub 自动生成的源码归档，不附带本机数据或安装包。
