# Mabobot v3.10.2：微信兼容性验收与媒体预览恢复

- 修复启动器操作刷新与定时轮询重叠后停止更新的问题，兼容性检测进度及结果持续自动显示。
- 兼容性检测自动显示微信主窗口并准备聊天场景；无当前会话时打开文件传输助手，不自动发送消息或下载文件。
- 新增人工功能验收，可逐项记录通过、失败或受阻及操作证据；定位检查与全部功能验收通过后，才能明确标记当前版本适配配置已验证。
- 验证标记绑定配置指纹，配置修改或复制到新版本后需重新验证；本地报告与截图仍仅保存在本机。
- 改进图片、视频预览窗口发现，补充按进程和窗口身份核对的句柄识别；重试点击超时后仍检查已打开的预览，减少遗漏，同时保留用户原有预览窗口。

更新后完整退出并重新启动启动器及后端服务。配置“已验证”标记不替代本机定位检查，也不代表本次发布已实测所有微信版本；请在自己的微信环境完成必要验收。备份格式与插件 Runtime API 保持 v2。
