# Mabobot v3.7.0：共享浏览器与模型价格发现

## 共享 Chrome

- 将浏览器生命周期从摘要插件抽取为公共服务，统一调试端口检查、启动、连接重试、受管浏览器恢复和驱动清理。
- 网页摘要、电子书下载、游戏日历封面和 Google 以图搜图复用共享 Chrome；连接失败可自动恢复，浏览器重启后旧会话重新连接。
- 摘要后台页面和视频 Cookie 读取通过公共 CDP 接口复用登录状态。插件停止只清理自身临时连接，保留共享浏览器。
- 插件无需先启用摘要插件；共享浏览器配置继续兼容摘要插件现有设置。网站账号仍需在受管 Chrome 中登录。

## 模型计价与聊天

- 未知 Codex GPT 模型触发异步官方价格查询，不阻塞当前回复；校验精确模型、官方来源、USD 单价和长上下文阈值后保存。
- 查询失败保留未知价格，六小时后允许重试；同时最多执行一个查询。
- 后续请求按已发现价格计费，支持长上下文分档；缺少适用缓存写入单价时不虚构价格。历史记录不自动重算。
- 调整内置聊天角色的观点表达规则，要求判断明确、立场随新事实修正。

## 升级说明

更新源码后完整重启启动器、Bot 与 Web，并刷新控制台。保留 `.env`、`data/` 和现有浏览器 Profile；备份格式和插件 Runtime API 仍为 v2。

价格发现需要可用的 Codex Profile 与联网能力；无法验证官方价格时继续显示未知，不影响正常回复。
