# Mabobot v3.6.0：后台任务、备份恢复与存储管理

## 助手任务与微信处理

- 长任务可转入后台，支持按编号查询、取消、补充指示与完成后继续，保留独立会话分支和发送记录。
- 新增任务最长执行时间与连接恢复等待设置；保存设置时正在执行的任务继续运行。
- 加强图片预览窗口归属校验和失败恢复，提前保存普通及引用图片；超过 10 分钟的积压消息仅存档。
- 改进小红书图片地址去重、校验与失败清理，修复正文图片处理；增加微信 4.1.13.65、4.1.15.11、4.1.15.13 定位配置。

## 备份与恢复

- 完善状态备份和完整迁移，纳入日志模块、独立 Codex Profile 配置、凭据与 Skill，可选择不包含 Profile。
- 完整校验后准备恢复计划，支持取消；启动器在所有服务打开数据库前恢复，失败时阻止启动并回滚。
- 修正跨用户 Profile 路径和脚本，完善旧备份兼容性提示、导入进度与恢复报告。
- 备份未加密，可能包含 API Key、登录凭据和聊天数据，请妥善保管。

## 存储与日志

- 新增存储空间管理：分类扫描、缓存清理预览、移入回收区、恢复与永久删除。
- 聊天附件、档案、数据库、模型与运行环境只做统计；清理需确认，恢复不会覆盖同名新文件。
- Web、Bot、mabowx、启动器与自动登录统一 JSONL 日志字段和有界保留，运行中心支持来源、级别、事件、关联 ID 与时间筛选。
- 概览区分 Bot 发送、聊天回复和插件处理轮次，完善最近问题聚合与系统页面交互。
- 补充 GPT-6 模型用量计价。

## 升级说明

升级前备份运行数据；更新源码并安装依赖后，完整重启启动器、Bot 与 Web，刷新控制台。保留 `.env` 与 `data/`，备份格式仍为 v2，插件 Runtime API 仍为 v2。旧 v1 备份不能直接恢复到当前版本；缺少日志模块的旧完整迁移包需重新创建。外部 Python、微信、WSL 与 Codex 环境仍需在目标机器安装。
