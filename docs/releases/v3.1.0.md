# Mabobot v3.1.0：媒体可靠性、引用视频与自动记忆维护

本版修复微信图片取样坐标错误，新增引用视频问答和电子书下载，并完善长期记忆自动维护与小红书图文处理。

## 微信图片与引用视频

- 修复微信 Qt 窗口区域截图坐标错误：完整绘制窗口后再裁剪消息行，避免错误像素导致图片定位、点击和结果校验异常。
- 图片下载增加请求关联、操作阶段、等待耗时和窗口状态诊断，并保留底层文件 DEBUG 日志。
- 支持引用视频问答：按需取得视频，在本地抽取 4 张等时段画面供助手分析。该功能基于抽帧，不包含完整音轨转写。

## 电子书下载

- 新增“找书”“下载电子书”“电子书”命令，支持书名、作者、ISBN 和 DOI。
- 支持候选作品选择、语言确认、格式偏好及下载前检查；候选回复按聊天和发起用户隔离。
- 在 Mapping 页面配置 `ebook_downloader.parse_request` 模型，并使用 Summary Plus 的共享 Chrome 设置；需要已可用的浏览器及目标网站会话。
- 公开版现在包含 7 个插件，新增电子书下载。浏览器配置和操作锁与 Summary Plus 共享。

## 记忆与管理界面

- 人物记忆新增独立后台维护，不再完全依赖下一条聊天消息触发；低活跃人物达到最低消息量及等待期限后也会进入处理流程。
- 有未投影观察的人物资料可按最长等待期限刷新；确认稳定身份后自动合并重复身份，并保留可撤销审计。
- 证据不足内容自动隔离，管理界面保留误判纠正入口。
- 回复前过滤无关阶段摘要，高敏感人物记忆默认不注入；事件与阶段记忆的原有数量门槛保持不变。
- 修复聊天策略表单对插件开关变更的识别。

## 小红书图文

- 合成长图时追加笔记正文及作者信息；含正文的单图笔记也使用此流程。
- 正文卡片支持中文换行、话题标记整理及中文字体回退。

## 升级说明

使用 Git 安装的用户执行 `git pull`；使用压缩包的用户请将新版本完整解压到新目录，按既有备份/恢复流程迁移配置与数据。随后完整退出 Mabobot，并重新运行 `START.bat`。

本版必须重启微信 Bot，才能加载截图修复并清除旧取样产生的消息身份缓存；历史失败图片不会自动重新下载。截图修复会增加单次临时像素缓冲，窗口越高、同时处理的图片越多，开销越明显。

发布包不包含真实密钥、Cookie、浏览器登录资料、聊天记录或运行数据库；这些配置和数据保留在用户本机。
