# Mabobot v3.3.0：Codex 会话、附件交付与微信兼容性

本版汇总 v3.2.2 之后的公开更新，完善 Codex 会话指令与文件交付，新增微信兼容性检查，并减少网页摘要和链接解析对日常聊天的干扰。

## Codex 会话与附件

- 角色规则通过会话级 developerInstructions 注入，各群继续使用独立持续会话，无需为每个角色创建 Profile 或修改前端配置。
- 旧会话在后续调用中自动接入新指令通道；迁移失败保留历史并报错。运行环境会检查所需 Codex 协议能力。
- 最终回复明确选择需要发送的附件，排除参考图、中间素材和废弃版本。宿主校验文件来源、类型与内容，原生图片仅接受本次成功工具事件授权的路径。
- 保留角色 JSON、拟人分条和多图顺序；附件路径不会混入微信正文，正常交付不额外增加模型轮次。
- 回复成功数按业务轮次去重，保留真实请求次数、Token 与费用；已有统计自动重算回复数，不重置用量历史。

## 微信兼容性与媒体

- 启动器新增微信兼容性面板，支持版本检测、只读定位检查、报告对比和手动设置基线。
- 定位规则按微信版本独立维护，新版本沿用最近旧配置并标为待验证。定位检查通过不代表发送、下载等完整功能已验收。
- 明确请求的引用图片可在模型排队前提前保存；预取遵循聊天启用状态与发送者限制，读取失败时向明确触发的用户说明原因。
- MP4 文件不再接收时预下载；增强链接卡片和引用媒体诊断。
- 忽略微信更新弹窗前检查前台、遮挡和按钮状态，降低误点风险。

## 监听与后台摘要

- 链接解析采用独立串行锁与短 UI 事务，等待浏览器期间释放桌面锁；复制链接时原子保存和恢复文本剪贴板。
- 已交付长消息的尾部仍可识别时直接衔接新消息，减少无意义的历史上翻和离屏头像重解析。
- 网页摘要通过现有 Chrome 的后台标签页读取内容，结束时只关闭本次页面，不切换用户当前标签页；B 站登录态读取不再新开交互标签页。

## 升级

1. 更新源码并安装更新后的 requirements.txt 依赖，保留现有 `.env`、`data/` 和本机配置。
2. 完整退出并重新打开桌面启动器，同时重启 Bot 与 Web 服务；仅重启服务不会更新启动器本身。刷新 Web 页面加载新资源。
3. 若 Codex 协议兼容检查失败，通过现有 Codex 升级流程更新 CLI。本版不变更备份格式或插件运行接口版本。
4. 微信定位配置仍标为待验证；请按报告检查实际使用的版本。兼容性报告和截图仅保存在本机，不包含在发行归档中。
