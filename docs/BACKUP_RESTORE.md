# 系统备份与恢复

状态备份包含 `.env`、数据库、助手全局配置、微信内容策略、聊天档案、附件、托管插件状态，以及 Mabobot 管理的独立 Codex Profile 配置、凭据和 Skill。完整迁移额外包含当前项目代码、启动器、mabowx 资源与所选生成内容；包含新版启动所需的 `mabobot_logging.py`。

Profile 来自当前运行用户的 `~/.codex/mabobot-profiles` 和 `~/.local/bin/codex-profile-*`。Windows 使用 WSL 时从默认 WSL 用户目录读取。备份不包含全局 Codex 登录、Profile 会话数据库或下载的插件缓存。WSL 无法访问、Profile 配置或启动脚本不完整时会报告失败，不会静默跳过。不使用 Codex 或只需备份项目数据时，可在“范围”中取消“独立 Codex Profile 与 Skill”；该选择会记录在备份清单中。

测试或自定义部署可以通过 `SYSTEM_BACKUP_CODEX_USER_HOME` 指定 Profile 所属用户目录；若 Windows 文件访问路径与 Linux 运行路径不同，另设 `SYSTEM_BACKUP_CODEX_RUNTIME_HOME`。通常不需要设置这两个变量。

恢复到不同用户目录时，会重建 Profile 元数据和启动脚本，并更新配置中的 Profile 路径。目标运行环境须先装好 Codex 并可通过 PATH 找到。迁移的 ChatGPT Profile 使用独立登录文件，避免被目标机器的全局账号覆盖；登录已过期时仍需重新登录。Python、微信、WSL 和其他外部工具需在目标机器安装。

在 Web 页面准备恢复后，使用启动器“重启全部服务”。启动器会在任何服务打开数据库前执行恢复；只重启 Web 而 Bot 仍运行时会拒绝恢复。恢复前创建安全快照，清除待替换 SQLite 数据库的旧 WAL/SHM/journal；中途失败会回滚数据库及旁文件。手动调用恢复也必须停止 Web 和 Bot。

v1 旧备份现在会在列表显示“不兼容”，可下载保留，但不能直接恢复到当前版本。请用对应旧版本导出数据后迁移；不会尝试自动覆盖当前数据库。旧 v2 备份仍可读取，但若其中的启动代码依赖缺失的日志模块，会校验失败。修复前漏掉的配置和 Profile 不会凭空出现在旧包中，应重新创建备份。

备份尚未加密，包含 `.env`、API Key、Profile 登录凭据及聊天数据，应按敏感文件保管。校验只证明已登记文件的完整性与基本结构，不等于目标机器所有运行环境已经安装完毕。

## 页面操作流程

- **创建备份**：点击“创建备份”，选择日常状态备份或完整迁移，检查固定范围与附加内容后直接创建。创建表单明确提示未加密及凭据范围，不再重复弹出普通确认框。选项在当前浏览器标签页中保留，刷新列表、刷新页面或任务结束均不会重置；恢复确认文字不会持久保存。
- **导入备份**：选择 `.mabobot-backup.zip` 文件，查看上传进度和结构检查结果。导入仅添加记录，不应用数据；需要恢复时从记录的“恢复”继续。
- **恢复备份**：选择记录后自动定位到影响说明，输入“恢复备份”并点击“校验并准备恢复”。系统完整校验后显示“恢复计划已准备，尚未应用”。此时可“重启全部服务并恢复”，也可“取消恢复计划”。关闭页面或取消重启确认不会撤销计划；取消计划会保留归档和当前数据。已有计划时不能静默替换为另一份备份。
- **结果与异常**：后台任务期间禁用冲突操作。连接中断后显示重连提示，可刷新读取任务状态。记录区展示近期完整校验结果，和结构检查明确区分；“最近任务”展示服务保存的任务结果，最多基于最近 80 条备份任务。重启后通过“上次恢复”查看恢复报告和安全快照名称。

恢复计划取消接口为 `POST /api/backups/cancel-restore`，要求 `archive_name` 与当前计划一致，且 `confirmation` 为“取消恢复计划”。计划已变化时返回 409，防止旧页面取消另一份计划。备份概览新增 `last_restore`，从既有恢复报告读取，既有备份格式保持兼容。
